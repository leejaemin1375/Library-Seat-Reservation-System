# 열람실 예약 기능

## 파일 구성
- `reading_room2.py` : 열람실 예약 메인 코드
- `reading_rooms.json` : 예약 데이터 저장 파일 (최초 실행 시 자동 생성)

## 화면 구성
열람실 목록 → 좌석 배치도 → 예약 확인 → 완료

## 주요 기능

### 열람실 목록
- 열람실별 현재 사용 중 / 전체 좌석 수 표시
- 카드 클릭 시 좌석 배치도로 이동

### 좌석 배치도
- 좌석 상태를 색상으로 구분
  - 🟢 초록 : 배정가능
  - 🟣 보라 : 사용중 (종료 시간 표시)
  - 🔴 빨강 : 배정불가
- 좌석 수가 많은 경우 스크롤 지원

### 예약
- 배정가능 좌석 클릭 후 확인 팝업으로 예약
- 예약 시간 : 현재 시간 기준 3시간
- 1인 1좌석 제한 (중복 예약 방지)

### 내 예약 정보
- 예약 열람실 / 좌석 번호 / 종료 시간 확인
- **시간 연장** : 종료 시간 1시간 연장
- **자리 이동** : 다른 열람실 포함 좌석 변경 가능, 기존 종료 시간 유지
